A Node program that writes one original poem about agency — the power to choose and to act, and what remains yours when you hand the doing to an agent — to `/output/entry.txt` for make.fun's "Write the best poem about agency" bounty.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
